# PNG Maker

학습지 PNG를 브라우저 안에서 문항별로 잘라 수업에 사용할 순서로 내려받는 로컬 편집기입니다. Python 3로 `python preview.py`를 실행한 뒤 [로컬 편집기](http://127.0.0.1:18861/)를 엽니다. 제공되는 예제는 브라우저에서 그립니다. 파일 선택, 자동 영역 제안, 좌표 및 경계 편집, 분할, 실행 취소, 정렬, PNG·ZIP 생성은 현재 탭에서 처리됩니다. 새로고침하면 편집 내용이 사라집니다.

## 편집과 다운로드

1. PNG를 엽니다. A4는 300dpi를 권장합니다. 입력 한도는 64MiB, 1,600만 픽셀, 한 변 16,384px입니다. 기존 편집이 있을 때는 새 파일을 검사한 뒤 교체 여부를 묻습니다.
2. 원본과 제안 경계를 대조합니다. 구분선 밖의 후보에 실제 문항이 있으면 선택 후 **여백 제외에서 보호**를 누르고, 나머지 여백 후보를 함께 제외합니다.
3. **선택 범위만 정렬**에 연속된 시작·끝 번호를 입력하면 해당 묶음만 왼쪽 열부터 정렬됩니다. 순번을 한 칸씩 바꾸거나 실행 취소할 수도 있습니다.
4. 경계와 순서를 확인한 뒤 선택 PNG 또는 전체 ZIP을 받습니다. `분수 연습.v2.png`의 결과는 `분수 연습.v2_변환.zip`입니다. ZIP 항목과 개별 다운로드 모두 최종 순번에 따른 `분수 연습.v2_변환_문제01.png` 형식을 사용합니다. 내부 영역 ID는 이름에 노출되지 않습니다.

## 검증

테스트용으로 Node.js, Playwright, Chrome, Python 3 및 Pillow가 필요합니다. 저장소 루트에서 실행합니다.

```powershell
npm install
python -m pip install Pillow
python tests/run.py
```

테스트는 비어 있는 로컬 포트에서 이 저장소의 서버를 띄우고, 임시 폴더에 도형으로 만든 합성 PNG를 생성합니다. Windows Chrome에서 구분선이 있는 경우와 없는 경우를 1,440px 마우스 및 390px 키보드로 시험합니다. 각 경로에서 7개 영역, 정렬 전후 ZIP, 개별 PNG 7개를 실제 다운로드하여 원본 픽셀과 대조합니다. 390px은 브라우저 뷰포트입니다.

18861 검증에서 2–5번만 정렬한 뒤 1·6·7번의 순서·ID·좌표·PNG 바이트가 그대로였고 모든 경로에서 누락·잘림이 0건이었습니다. 8개 ZIP과 개별 PNG 28개를 비교했으며 Windows PowerShell의 Expand-Archive로 한글 항목 이름도 확인했습니다. 빈 이름, 예약 이름, 금지 문자, 긴 한글 이름, 역순 범위, 초과 입력·교체 취소의 보존 동작을 별도로 검사합니다.

**대기 항목**은 동일 픽셀의 PNG에서 해상도 정보 유무에 따른 한컴 A4 기본 삽입 폭(mm)을 직접 측정하는 일입니다.
