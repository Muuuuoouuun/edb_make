PNG Maker · Windows 로컬 배포 후보
=================================
ZIP 전체를 압축 해제한 뒤 PNG Maker.exe를 엽니다.
다른 런타임 설치가 필요 없습니다(Windows에 포함된 .NET Framework 4.x/기본 브라우저 사용).
브라우저가 열리지 않으면 앱 창의 주소를 복사해 Edge 또는 Chrome에 붙여넣으세요.
편집이 끝날 때까지 PNG Maker 실행 창을 열어 두세요.

1. PNG 열기: EDB Maker에서 만든 PNG도 열 수 있습니다. 원본은 변경되지 않습니다.
2. 문항의 경계와 순서를 확인합니다. 실행 취소 버튼 또는 Ctrl+Z를 사용할 수 있습니다.
3. 확인 체크 후 파일 이름과 순서를 미리 보거나 PNG/ZIP을 내려받습니다.
4. 파일은 [원본명]_변환.zip 및 [원본명]_변환_문제01.png 형식입니다.
5. 브라우저에 전달했다는 안내 후 Ctrl+J에서 실제 저장 여부를 확인합니다.

파일은 브라우저 탭에서 처리합니다. 다운로드 요청 기록은 해당 탭에만 있고
성공적으로 브라우저에 전달한 형식과 영역 개수를 최대 10건 기억합니다.
파일 이름·원본·좌표를 기록에 넣거나 외부 알림을 전송하지 않습니다.
새 이미지로 교체하거나 탭을 닫으면 작업과 요청 기록을 되돌릴 수 없습니다.
배포 후보는 코드 서명하지 않았습니다. 조직 정책이 실행을 차단하면 예외를 만들지 말고 관리자에게 문의하세요.
