각 반복은 새 앱 프로세스·브라우저 프로필·작업 폴더·원본 복사본으로 실행했다. 같은 작업 안의 미리보기→제작 캐시는 허용하고 이전 반복의 앱 캐시는 재사용하지 않았다. 새 관측 20개와 나머지 40개 출력의 디코딩 이미지·배치·순서·원본 연결 정보가 정확히 같은지 검증했다. 이전 연구의 품질 측정이나 시간을 재사용하지 않았으며, 실패 회차를 숨기거나 좋은 반복만 골라내지 않았다.

측정 시간은 앱 실행부터 실제 다운로드 저장 완료까지다. 클릭 후 진행 표시의 최대 지연은 **177.12ms**로 250ms 예산을 만족했다. Linux x86_64, CPU 할당 4코어, Chromium 154, 로컬 처리·AI/OCR 미사용 조건이다. 서버 최대 RSS는 약 2.51GiB였다. 과거 측정과의 메모리 여유가 달라 이 표를 특정 수정의 인과적 속도 향상 증명으로 사용하지 않는다.

실제 다운로드 60건의 EDB 75개를 파싱하고 출력 내용을 대조했다. **파일별 칠판 최대 50페이지**를 확인했다. 의미 있는 글자·기호 손실, 문항 혼입, 중복·역순·잘못된 합치기, 손상된 파일, 잘림, 입력 변조, 앱 오류·미완료는 평균 점수로 상쇄하지 않는 필수 실패 조건이다. 과목 미지정 전체 페이지에서 손상됐던 θ도 실제 앱의 세 출력 모두 보존 검사를 통과했다. ClassIn 프로그램의 GUI에서 실제로 열기는 별도 미확인 항목이다.

정답·원본·평가 정책·소스·측정기 해시를 고정했다. 별도 검토에서 점수 계산기를 가져다 쓰지 않고 모든 점수를 다시 계산했으며 **2,858개 확인**을 통과했다. 로컬 전체 테스트 **2,759개 + 하위 검사 564개 통과**, 45개 건너뜀, 기존 Pillow 경고 2건이었다. 프런트엔드 패키지 검사와 GitHub CI도 통과했다. 합성 회귀 자료의 점수는 위 실측 점수에 넣지 않았다. Claude API 키는 현재 실행 환경에 제공되지 않아 외부 Claude 호출은 하지 않았고 독립 에이전트 검토를 사용했다.

이전 실패 평가와 원본 증거는 보존했다. 검증기 수정은 바이트가 동일한 정상 출력의 앤티앨리어싱·회색 도형 오판을 재현해 교정했으며, 글자 삭제·구멍 채우기·순서 교체·회색 배경에 복사 추가 등의 실패 검사는 유지했다. 정답과 통과 임계값은 변경하지 않았다. 최종 V7 관측은 모든 20개 자료/모드에서 새로 측정했다.

Windows·Mac Apple Silicon·Mac Intel **0.2.13 내부 설치 파일**도 같은 평가 소스로 재빌드하고 업데이트 검증했다. 다운로드 링크, PIN·배포 주소 설정, 코드 서명 상태와 검증 범위는 [내부 빌드 보고서](0.2.13-internal-build-validation.md)에 있다. 이후 변경은 빌드 증빙 업로드와 테스트·결과 문서에 한정되며 앱 실행 코드는 평가 커밋과 동일하다.
