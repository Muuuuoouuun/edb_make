# 인식·그림 원본 보존 개발 상태

## 판단

예전 계획은 현재 구조를 재사용해 단계적으로 구현할 수 있다. 문항 분할과 그림 색상 보존은 다른 단계다. 문항은 번호·본문·그림·선택지를 하나로 유지하고, 보존 처리는 문항 안의 제한된 영역에만 적용한다.

| 예전 작업·계획 | 현재 상태 | 이번 범위와 다음 작업 |
| --- | --- | --- |
| PDF 내부 사진·표만 원본 유지 | 기존 구현 | PDF 좌표·신뢰도 필터와 크롭 좌표 변환을 재사용한다. |
| JPG·PNG/스캔의 컬러 그림 구분 | 이번 코드 초안 구현 | 로컬 색상·연결 성분으로 크기가 충분한 컬러 영역만 후보로 삼는다. 새 모델·API 호출은 추가하지 않는다. |
| 수학의 컬러 그림 보존 | 이번 코드 초안 구현 | 수학을 일괄 단색화하던 정책에서, 색상 정보가 충분한 그림만 원본으로 복원한다. 흑백 도형은 기존 초크 처리를 유지한다. |
| 미리보기·저장·최종 EDB의 색상 일치 | 새 인식 결과 경로 구현 | 영역 좌표를 세션에 보관하고, 최종 초크 정규화·리사이즈 뒤 원본 영역을 다시 합성한다. |
| 수동 크롭·지문 이어붙이기 뒤 영역 유지 | 이번 코드 초안 구현 | 자동 모드는 새 이미지에서 다시 검출한다. 수동 모드는 원본 페이지 좌표와 실제 이어붙이기 위치로 이동·교차 영역을 계산한다. 보존 끄기도 유지한다. |
| 보존 영역의 표시·수정·해제 UI | 이번 코드 초안 구현, 브라우저 QA 통과 | 자료 상세 → 그림 원본 보존에서 영역 드래그·숫자 수정·삭제, 자동 재감지·보존 끄기를 제공한다. 2단계 전용이며 최대 16개 영역이다. |
| 기존 AI 보정 응답에서 그림 좌표 받기 | 미구현, 구현 가능 | 보정 응답 스키마·검증·캐시 버전을 함께 바꾸면 별도 그림 검출 요청을 줄일 수 있다. 현재 구현은 이 응답을 사용하지 않는다. |
| 흑백 사진·희미한 컬러 선 그래프까지 자동 구분 | 추가 자료 필요 | 색상만으로 판정할 수 없다. 실제 정답 좌표가 있는 자료와 검수 수단을 먼저 준비한다. |
| 실제 시험지 인식 정확도 수치화 | 검사 하네스 존재, 실측 별도 | 합성 이미지나 AI 출력 자체를 정답으로 삼지 않고 사람이 확정한 원본·정답으로 측정한다. |
| 초해상도·생성형 복원 | 기존 보존형 처리·선택적 백엔드 존재 | 불명확한 글자·수식의 의미를 복원했다고 간주하지 않는다. 원본 대조와 검토 상태가 필요하다. |

## 새 컬러 후보 검출기

- [raster_media.py](../raster_media.py): 분석 영상의 긴 변을 960px로 제한한다. 출력 원본은 줄이지 않는다.
- 작은 컬러 번호, 긴 형광 표시, 페이지 테두리, 단색 종이 전체, 투명한 색상 픽셀은 자동 보존 대상에서 제외한다.
- 명확한 PDF 보존 좌표가 있으면 그 경로를 먼저 사용한다. 좌표가 없는 새 문항 크롭에만 로컬 후보를 추가한다.
- [build_problem_board_edb.py](../build_problem_board_edb.py): 보존 대상의 원본 RGB 픽셀을 마지막에 복원한다. 영역 바깥의 본문·선택지·도형 픽셀은 기존 초크 출력과 동일하게 유지한다.
- 수학의 PDF 매체 영역은 색상 면적을 추가 확인한다. 아주 작은 컬러 표시 하나 때문에 문항 전체를 흰 사각형으로 복원하지 않는다.
- `confidence=0.9`는 기존 메타데이터 필터와 연결하기 위한 휴리스틱 표식이다. 실측 정확도 90%를 의미하지 않는다.

현재 검출은 의미 기반의 사진/도형 분류기가 아니다. 희미한 파스텔·가는 컬러 선·작은 그림·회색조 사진·문항 대부분을 차지하는 큰 그림은 후보에서 빠질 수 있다. 원본 사각형 안의 흰 배경도 원본대로 남는다. 이미 보존된 흑백 PDF 사진/표의 기존 동작은 유지한다.

공통 지문의 하위 문항은 기존 정책대로 자동 보존 대상에서 제외한다. 사용자가 직접 지정한 영역은 흑백 그림도 보존한다. 원본 보존 설정은 세션 저장·불러오기·게시 후에도 유지한다.

새 일반 문항은 크롭의 여백·수평 정리 오프셋(`cropSourceOffset`)도 기록한다. 새 수동 이어붙이기는 각 원본 조각의 실제 출력 좌표(`sourceSegments[].cropBbox`)를 기록하며, 이어붙인 자료의 여백 자르기는 합쳐진 이미지 자체를 자른다. 이전처럼 첫 페이지를 다시 잘라 나머지 페이지를 잃지 않는다.

이전 세션의 누락된 위치 정보는 추정해서 붙이지 않는다. 원본 위치가 불명확한 옛 패딩 크롭은 수동 그림 지정 후 영역 변경 시 자동 감지로 전환하라는 안내를 반환한다. 출력 위치 정보가 없는 옛 이어붙이기는 원본에서 다시 이어붙인 뒤 여백을 자를 수 있다. 기존 세션 전체를 자동으로 소급 복구한 상태는 아니다. 문항 갈라내기·합치기·일괄 분할의 보존 설정 이관은 별도 범위다.

## 검증 방법

[test_raster_media_preservation.py](../test_raster_media_preservation.py)는 해상도별 후보 좌표, 장식 오검출, 원본 입력 불변, 영역 바깥 픽셀 동일성, 수학 컬러 보존, 리사이즈 후 최종 인코딩, JSON 세션 저장을 검증한다. 기존 [test_selective_media_preservation.py](../test_selective_media_preservation.py)의 흑백 수학 도형·PDF 보존 회귀 검사도 함께 실행한다.

[test_app_server_media_preservation.py](../test_app_server_media_preservation.py)는 자동·수동·끄기, 크롭·초기화·다중 페이지 이어붙이기·이어붙인 이미지의 재크롭, 원본 위치가 없는 이전 세션, 패딩 오프셋, JSON 저장, 최종 PNG 인코딩, 게시 메타데이터 및 리비전 검사 API를 검증한다. [test_ui_media_preservation.py](../test_ui_media_preservation.py)는 표시 배율을 원본 픽셀로 변환하는 드래그, 숫자 수정·범위 제한, 삭제·자동·끄기, 저장 실패 시 편집 유지와 설정 저장을 컴포넌트 이벤트 단위로 검증한다. 이 단위 검사는 실제 브라우저의 렌더링·콘솔·화면 조작을 대신하지 않는다.

```bash
python -m pytest -q test_app_server_media_preservation.py test_ui_media_preservation.py test_raster_media_preservation.py test_selective_media_preservation.py test_image_question_boundaries.py test_edb_publish_flow.py
```

이 검증은 합성 정답 자료를 사용한다. 실제 시험지에서의 검출 정밀도·재현율이나 수식 의미 보존을 입증하는 수치는 아니다. 실제 자료 검증은 [품질 게이트](QUALITY_REGRESSION_GATE.md)의 독립 정답·출처 기준을 따른다.

같은 합성 컬러 그림에서 탐지기만 15회 실행하고 앞의 3회를 제외한 중앙값은 다음과 같다. 기존 라이브러리만 사용하며 외부 API 호출은 없다. 단일 호스트의 예시 측정이므로 앱 시작/전체 문서 처리 성능으로 확대 해석하지 않는다.

| 문항 크롭 크기 | 추가 탐지 시간 중앙값 |
| --- | ---: |
| 1100×700 | 13.17ms |
| 2200×1400 | 22.11ms |
| 3300×2100 | 35.11ms |

## 다음 적용 순서

1. 새 인식 결과와 수동 편집 경로의 회귀 검사를 실행한다.
2. 실제 브라우저에서 자료 상세 → 그림 원본 보존 → 수정·저장 → 새로고침·재열기 → 끄기·자동 재감지 흐름을 검증했다. Browser 스킬의 연결 도구가 제공되지 않아 사용자 허용에 따라 Playwright 1.62.1 + 시스템 Chromium 154로 대체했다. 로컬 `http://127.0.0.1:8765/board.html`, 1440×1000 및 열린 편집 창을 390×844로 축소하는 경로에서 영역 드래그·숫자 수정·설정 유지·ESC 닫기·콘솔 오류 없음을 확인했다. 좁은 창에서 사이드패널과 함께 편집 창이 숨던 문제는 문서 본문으로 포털을 이동해 수정했다. 합성 문항으로 확인했으며 다른 브라우저·네이티브 설치본은 이번 화면 QA에 포함하지 않았다.
3. 실제 컬러 사진·과학 도표·수학 색상 그래프·색상 본문 자료에 사람이 확정한 그림 좌표를 붙인다.
4. 문항 누락/병합, 그림 오보존, 글자·수식 변경, 추가 처리 시간과 파일 크기를 함께 측정한다.
5. 검수 기능과 실제 자료 기준을 통과한 범위를 기준으로 기본 적용 범위를 결정한다.
