# 지문 전용 추출·배치 품질 점수표

## 통과 기준

- 범위 감지율 100%
- 지문 전용 결과에 문항 레코드 0개
- 모든 결과의 처리 단계 S2
- 모든 결과의 시작 x 비율 0
- 인접 레코드 겹침 0건, 간격 20px
- 여러 조각 결합 시 글자 스케일 변경 없음
- 명시한 처리 단계는 지문 전용 기본값보다 우선
