## 통과 기준

- 범위 감지율 100%
- 지문 전용 결과에 문항 레코드 0개
- 모든 결과의 처리 단계 S2
- 모든 결과의 시작 x 비율 0
- 인접 레코드 겹침 0건, 간격 20px
- 여러 조각 결합 시 글자 스케일 변경 없음
- 명시한 처리 단계는 지문 전용 기본값보다 우선

## 자동 평가 항목

지문 전용 결과에는 `passageQuality`가 포함된다. 점수는 단순 화질 한 항목이 아니라 다음 근거를 합산한 0~10점이다.

- 공통 지문 판별 신뢰도: 문항 범위와 `읽고/보고 + 물음에 답하기` 유형의 지시문을 함께 확인한다.
- 텍스트 레이어 범위: 지문 crop 안에 포함된 줄 수와 공백 제외 글자 수를 기록한다. 원문 텍스트가 없는 스캔은 이 항목을 점수에서 제외한다.
- 텍스트 경계 보존: 지문에 배정된 각 텍스트 박스가 crop 경계 안에 완전히 포함되는지 검사한다. 긴 머리말 등의 일부가 잘리면 `passage_text_bounds_clipped`으로 표시하고 `good` 등급을 허용하지 않는다.
- 이미지 해상도: 원본 DPI와 지문 crop 너비를 함께 평가한다. 144 DPI 미만 또는 480px 미만은 경고한다.
- 글자 선명도: 원본과 1px 흐림본의 차이값으로 획 경계 선명도를 측정한다. 임계값 미만은 `blurry_passage_crop`으로 표시한다.
- 내용 밀도: 거의 빈 crop과 지나치게 빽빽한 잘못된 crop을 경고한다.

등급은 `good`(8.5 이상), `review`(6.5 이상), `poor`(6.5 미만)이다. 지문 전용 인식 결과 화면에는 평균 텍스트·화질 점수와 확인 필요 개수가 표시된다.

## 공통 지문 오탐 방지

- `[1~3]`처럼 숫자 범위만 있는 문장은 공통 지문으로 인정하지 않는다.
- 글/자료/대화/도표 등의 공통 자료 지시와 읽기·보기·답하기 과제가 동시에 있어야 한다.
- 같은 열에서 해당 범위의 첫 문항이 이미 시작된 뒤 나타난 범위 지시문은 문항 내부 내용으로 유지한다.
- 오탐 방지 규칙은 PDF 텍스트 레이어, HWP 빠른 텍스트 추출, 일반 OCR 블록 조립에 동일하게 적용한다.
