# 공통 지문·전체 페이지의 5항목 실측 평가

사용자 범위는 **여러 문항이 공유하는 공통 지문만**이다. 영어의 단독 독해 문항, 듣기 지시문, 문항과 선지는 지문 출력에 포함하지 않는다. 페이지 전체 넣기는 이를 포함한 원본 페이지 전체를 순서대로 보존한다.

국어/영어 × 공통 지문/전체 페이지의 네 그룹을 따로 집계한다. 각 그룹의 5항목 산술평균이 95/100 이상, 모든 항목이 93 이상이어야 한다. 빠르지만 내용이 없는 출력이나 잘못된 연결, 문항 혼입, 의미 있는 글자·기호의 손실, 원본 변조, 손상된 EDB는 평균으로 상쇄하지 않는다.

| 항목 | 측정 근거 |
|---|---|
| 추출·선택 정확성 | 원문 검토로 확정한 지문/페이지와 일대일 대응한 정밀도·재현율, 지문 영역 IoU 0.8 이상 |
| 원문·경계 보존 | 원본 PDF 렌더와 최종 EDB 내장 이미지를 독립적으로 대응시킨 전경·글자·기호·그림 보존, 문항·선지 혼입 |
| 연결·읽기 순서 | 확정한 원문 내용 단위·연결 관계와 출력의 순서·중복·연결부 보존 |
| 배치·내보내기 안전성 | 모든 EDB 독립 파싱·이미지 읽기, 내용 대응, 겹침·잘림 없음, 각 파일 칠판 50페이지 이내 |
| 속도·사용성 | 실제 화면에서 파일 선택→처리→미리보기→제작→다운로드를 새 프로세스·새 작업 폴더로 3회 측정 |

네트워크로 시험지를 받는 시간은 별도 기록한다. 공통 지문 시간 예산은 `min(300초, 10초+원본 쪽수×5초)`, 전체 페이지는 `min(300초, 10초+원본 쪽수×2.5초)`이며, 클릭 후 작업 표시 예산은 250ms다. 실패 뒤 예산을 올려 통과시키지 않는다. 속도 점수는 모든 반복의 p95와 작업 성공률로 계산한다. 동시 개발 중의 탐색 측정은 정식 결과와 구분한다.

원본·정답·평가 정책·코드·출력·측정 파일의 SHA256을 연결한다. 원문만 본 작성자와 별도 검토자가 확정한 정답을 사용하며, 구현의 `passageQuality`, 사전점검 `passed`, OCR 신뢰도는 독립적인 정답이나 실측 점수로 간주하지 않는다. 정답의 보수적인 바깥 상자는 정확한 픽셀 윤곽선이 아니므로 원문 글자 박스와 실제 원본 이미지를 함께 사용한다.

정식 반복의 총시간은 새 앱 프로세스를 시작한 시점부터 다운로드 완료까지다. 작업 표시 지연은 별도로 실제 파일 선택 동작부터 측정한다. 각 반복마다 새 브라우저 프로필·작업 폴더·원본 복사본을 사용해 이전 반복의 캐시를 재사용하지 않는다. 같은 작업 안에서 미리보기와 제작이 검증된 캐시를 공유하는 정상 동작은 허용한다. 실패한 시도도 기록하며, 내용이 동일한 반복의 보존 측정을 재사용할 때는 모든 EDB의 디코딩된 이미지·배치·순서·원본 연결 정보가 정확히 같은지 증명한다.

실제 원본, 실제 원본의 변형 스트레스 자료, 합성 회귀 자료를 각각 보고한다. 개발 자료로 본 문서를 미사용 검증 자료라고 부르지 않는다. 작은 고정 자료집에서 목표를 만족한 결과는 그 자료집에 대한 결과이며 모든 시험지·스캔 형식에 대한 보장이 아니다. ClassIn 프로그램에서 실제로 열기는 파서 검증과 구분한다.

- `scripts/measure_shared_passage_quality.py`: 원문 정답과 실제 공통 지문 출력의 원시 측정기.
- `scripts/evaluate_passage_page_quality.py`: 원본/정답/출력/반복 측정 증거가 연결된 관측값의 엄격한 집계기. 누락된 축·분모·화면 반복은 점수를 만들지 않고 `incomplete`로 처리한다.

실제 자료 PDF와 전체 원문 렌더는 저장소에 재배포하지 않는다. 원본의 출처·해시와 로컬 측정 증거를 결과에 남긴다. 이 문서에는 미측정 제품 점수를 기입하지 않는다.
