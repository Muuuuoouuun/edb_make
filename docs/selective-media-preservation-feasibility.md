# 2단계 내부 사진·표 선택 보존 가능성 테스트

## 결론

PDF 입력에는 구현을 완료했다. 기존 2단계 렌더를 그대로 만든 뒤, 지문/문항 내부에서 검출한 사진·그림·표 사각형에만 원본 픽셀을 다시 합성한다. 공통 지시문과 질문 텍스트는 보존 사각형에 포함하지 않으므로 기존 2단계 결과를 그대로 유지한다.

스캔 이미지와 HWP 렌더 입력은 현재 내부 매체 좌표가 없으므로 별도 검출기가 필요하다. PDF와 같은 신뢰도로 곧바로 자동 적용하는 것은 권장하지 않는다.

## 적용 상태

- 별도 모드를 추가하지 않고 기존 `s2`의 기본 동작으로 적용했다.
- PDF의 고신뢰 이미지·표만 원본으로 유지하고 나머지는 기존 투명 초크 변환을 그대로 사용한다.
- 공통 지문의 하위 문항(`child_question`)은 기존 2단계 처리를 유지한다.
- 스캔 이미지와 HWP처럼 신뢰할 좌표가 없는 입력은 자동으로 기존 2단계 결과를 유지한다.
- 검수 미리보기, 세션 재로딩, 최종 EDB 인코딩에 같은 보존 좌표를 전달한다.

## 테스트 범위

- 실제 지구과학 문항의 지도, 도표, 표 5개
- 실제 국어 공통문항 페이지의 그래프와 표 1개
- 각 변형 20회 반복
- 비교 순서: 원본 / 현재 2단계 / 사진·표 선택 보존 2단계
- 선택 보존은 기존 2단계 결과 위에 지정된 원본 사각형만 불투명 RGBA로 합성

## 결과

| 항목 | 결과 |
|---|---:|
| 샘플 수 | 6 |
| 현재 2단계 렌더 중앙값 | 74.9ms |
| 선택 보존 렌더 중앙값 | 79.4ms |
| 샘플별 추가 시간 중앙값 | 1.5ms |
| 가장 큰 추가 시간 | 7.3ms |
| PNG 크기 비율 중앙값 | 1.63배 |
| 파일 증가량 중앙값 | 약 41KB/자료 |
| 가장 큰 임시 패치 버퍼 추정 | 약 1.22MB |
| 보존 영역 밖 픽셀 동일성 | 6/6 완전 동일 |

테스트한 6개 PNG 합계는 약 664KB에서 998KB로 증가했다. 시험지의 회색조 도표와 표 기준이다. 실제 컬러 사진은 PNG 엔트로피가 높아 증가 폭이 더 커질 수 있다.

## 자동 영역 검출 비용

PDF 내부 이미지 블록과 표 좌표를 PyMuPDF로 읽어 별도로 측정했다.

| 코퍼스 | 페이지 | 이미지 후보 | 이미지 스캔 | 표 스캔 | 필터 후 표 후보 |
|---|---:|---:|---:|---:|---:|
| 지구과학 | 4 | 24 | 69.5ms/페이지 | 53.8ms/페이지 | 4 |
| 국어 | 16 | 20 | 26.1ms/페이지 | 41.2ms/페이지 | 4 |

현재 PDF 전처리는 이미 `page.get_text("dict")`를 사용하므로 이미지 좌표 수집은 기존 순회를 재사용하면 별도 스캔 비용 대부분을 없앨 수 있다. 표 검출은 16페이지 국어 PDF 전체에서 약 0.66초가 추가됐다.

지구과학 20문항에 PDF 이미지/표 후보를 문항 좌표로 매핑했을 때 20문항 모두에서 하나 이상의 후보가 잡혔다. 이는 이 코퍼스의 검출 범위 결과이며, 다른 제작사의 PDF까지 정확도를 보장하는 수치는 아니다.

## 인식 영향

선택 보존은 OCR과 문항 분할이 끝난 뒤의 출력 렌더 단계에서 적용할 수 있다. 따라서 기존 OCR, 지문 묶음 인식, 문항 번호 인식에는 영향을 주지 않는다.

테스트에서는 보존 사각형 밖의 픽셀이 현재 2단계 결과와 모두 동일했다. 공통 질문과 지시문을 사각형에서 제외하면 해당 텍스트도 픽셀 단위로 바뀌지 않는다. 보존 영역 안에서는 작은 글자, 회색 음영, 범례, 선 종류, 색상 차이를 잃지 않는 장점이 있다.

## 구현 권장안

1. PDF에서는 렌더 시점에 이미지 블록 좌표를 함께 저장한다.
2. 표는 `row_count >= 2`, `column_count >= 2`, 페이지 대비 면적 상한 같은 1차 필터를 적용한다.
3. 큰 외곽 테두리, `<보기>` 전체 박스, 공통 지시문 박스는 보존 대상에서 제외한다.
4. 페이지 좌표를 문항/지문 크롭 좌표로 변환해 `preserve_regions` 메타데이터로 보관한다.
5. 2단계 렌더 후 해당 사각형만 원본 픽셀로 합성한다.
6. UI에는 자동 검출된 보존 영역을 켜고 끌 수 있는 최소 검수 기능을 둔다.

스캔 이미지/HWP는 신뢰도 높은 로컬 검출 결과만 자동 적용하고, 애매하면 기존 2단계를 유지하는 fail-open 방식이 적합하다. 이미 Gemini 페이지 보정을 호출하는 페이지는 별도 API 호출을 추가하기보다 기존 응답에 `preserve_regions`를 함께 받는 방식을 우선 검토한다.

## 남은 위험

- 표 검출기가 큰 지문 테두리나 `<보기>` 박스를 표로 오인할 수 있다.
- 원본 영역은 흰 종이 사각형으로 남으므로 어두운 칠판 위에서 경계가 보인다. 사진에는 자연스럽지만 단순 선 도표는 현재 2단계가 더 나을 수 있다.
- 여러 PDF 조판기, 스캔본, 컬러 사진 코퍼스로 정밀도와 파일 크기를 추가 검증해야 한다.
- 현재 구조의 `IMAGE` 블록은 지문 전체를 뜻하는 경우가 있어, 그 블록 유형만으로 내부 사진을 판정하면 안 된다.

## 판정

- PDF 자동 베타: **진행 권장**
- 스캔/HWP 완전 자동: **추가 검출 코퍼스 후 진행**
- 모든 그림을 무조건 원본 보존: **비권장**
- 공통 질문을 제외한 고신뢰 사진·표만 선택 보존: **권장**
