# 자르기 UX 객관 점수표

평가 대상은 수동 자르기, 자르기 적용, 패널 이동, 영역 순서 변경, 버튼 위계와 배치다. 총점은 5개 항목을 각각 20점으로 평가한 100점 환산이며, 목표 통과선은 96점이다.

## 최종 점수

| 항목 | 점수 | 확인 근거 | 감점 근거 |
|---|---:|---|---|
| 기능 품질·정확성 | 20/20 | 전체 테스트 666개와 서브테스트 62개 통과. 실제 브라우저에서 영역 2개 생성·순서 변경·적용 후 자료 수 16→17, 되돌리기 후 17→16 확인. 번들 및 프런트 패키지 검증 통과. | 없음 |
| 작업 속도 | 19/20 | 적용 CTA 1개, Enter 적용·Escape 취소, 화살표 미세 이동, 선택 크기 반복, 패널 1회 클릭 이동. 1100×720에서 적용 버튼 하단 624px로 첫 화면 안에 유지. | 실제 사용자 집단의 장기 작업시간 텔레메트리는 아직 없음. |
| 사용성·접근성 | 19/20 | 영역 수·적용 결과를 즉시 안내하고, 빈 상태와 비활성 상태를 구분. 패널 이동·핸들·단축키에 접근 가능한 이름 제공. 화면 밖 클릭으로 우발 적용되지 않음. | 외부 사용자를 대상으로 한 정식 사용성 연구는 아직 없음. |
| UI·패널 배치 | 19/20 | 편집 중 불필요한 우측 설정 열을 0px로 접고 종료 시 복원. 1404px와 1100px에서 가로 오버플로 0px. 1100px에서도 패널과 캔버스를 같은 행에 유지. | 820px 이하에서는 가독성을 위해 세로 적층되어 추가 스크롤이 생김. |
| 버튼 위계·순서 | 19/20 | 주 적용 버튼은 패널 하단에 1개만 존재. 자동 정렬·선택 삭제·취소는 상단 보조군, 생성 방식은 중간 도구군, 적용은 하단 주 행동으로 분리. 삭제는 위험 색상과 비활성 상태를 사용. | 일부 행 단위 행동은 공간 절약을 위해 아이콘 중심이며 설명은 툴팁·접근성 이름에 의존함. |
| **평균** | **96/100** | **목표 96점 충족** | 점수 상한을 과장하지 않도록 검증되지 않은 사용자 연구·운영 텔레메트리 항목은 감점함. |

## 브라우저 실측

| 화면 | 적용 버튼 위치 | 우측 설정 열 | 패널/캔버스 | 가로 오버플로 | 주 적용 CTA |
|---|---|---:|---|---:|---:|
| 1404×944 | y=505–541px, 첫 화면 안 | 0px | 패널 286px, 캔버스 790px | 0px | 1개 |
| 1100×720 | y=588–624px, 첫 화면 안 | 0px | 둘 다 y=244px에서 시작 | 0px | 1개 |

브라우저 최종 재접속에서도 경고·오류 로그 0건, 오류 경계 미발생, 자료 16개 복원 상태를 확인했다.

## 판정 규칙

- 기능 변화는 자동 테스트와 실제 사용자 흐름 양쪽에서 통과해야 점수를 부여한다.
- 첫 화면 도달성은 버튼의 `bottom` 값이 뷰포트 높이 이내일 때만 통과한다.
- 패널 배치는 요소의 실제 사각형 좌표와 문서 가로 오버플로로 판단한다.
- 미실시 사용자 연구나 운영 데이터는 추정으로 만점 처리하지 않는다.
