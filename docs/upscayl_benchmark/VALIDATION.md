## 산출물 검증

- 노트북: nbformat 스키마 통과, 11개 셀 실행 오류 0건
- Python 스크립트: `py_compile` 통과
- HTML 보고서: artifact validation, package, browser verification 모두 통과
- 보고서 검사 뷰포트: 1440px, 390px
- 차트 2개, 표 2개, metric card 2개, 출처 대화상자 및 키보드 상호작용 확인

## 남은 불확실성

- 표본이 합성 8건, 실제 6건, 모델 비교 3건으로 작다.
- 실제 crop의 고해상도 정답 원본과 OCR/수식 의미 정답이 없다.
- Apple M4 한 대만 측정했으며 Windows/Vulkan 호환성은 미검증이다.
- Gemini/OpenAI API는 호출하지 않아 실제 지연과 의미 복원 품질은 비교하지 않았다.
- 로컬 비용에는 인건비, 장비 감가, 검수 비용이 포함되지 않는다.

PoC 착수 결정에는 충분하지만, 자동 적용 출시 전에는 100~300개 블라인드 표본과 Windows 장치 매트릭스 검증이 필요하다.
